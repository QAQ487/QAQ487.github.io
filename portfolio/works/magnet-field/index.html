Magnet Field

磁力がテーマの対戦アクション。2回目のチーム制作で、フレームワークをゲームエンジンへ作り直しながら開発した。

  • 10人
  • 磁力
  • エンジン化
  • 制作期間2026/4–7
  • 体制授業のグループ、10人。
  • 役割リードプログラマー · プログラムの大部分を担当
  • 基盤Ivy Engine

課題と学び

課題・苦労した点Challenge
  • 期間が短く、多くのアイデアを削る必要があった。何が重要で、何を手放すかの見極め。
  • ゲームの前に、フレームワークを Ivy Engine へ改称すること。
  • 機能の層。エンジン基盤、スクリプト、エンジン固有機能。
学んだことLearned
  • リードとして開発全体を計画し、時間を管理すること。
  • テクスチャを頼むとき、必要なものと、エンジンが受け付けるものを伝える。
  • デザインクラスの学生との交渉。

対戦アクション
概要
授業の10人チーム。リードプログラマーとして、フレームワークをゲームエンジン（Ivy Engine）へ作り直しながら開発した。
使用技術
C++ / Direct3D 11 / FBX SDK / Effekseer / Dear ImGui / nlohmann/json
動作環境・操作方法
  • Windows PC · マウス＆キーボード
  • 左クリックで引き寄せ、右クリックで反発、ホイールクリックで周回。
工夫した点 / 設計の理由
  • 自分で班を選んだ。プログラマー2人のうち、コードの大部分を自分が担当。
  • グラフィックとモデルの学生から、より良い品質を得るため。
既知の不具合・今後の改善
  • BGM が未実装。
  • 磁力エフェクトの見た目をさらに磨く。
クレジット
10人チーム：デザイナー5人（3Dモデル4人・2Dテクスチャ1人）・プランナー3人・プログラマー2人。
ダウンロード
実行ファイルとゲームのソースは非公開。使用エンジン（Ivy Engine）のソースは GitHub で公開中。 github.com/QAQ487/ivy-engine
