# FB-31 · Stasis with stored impact

**Aliases:** Stasis; Stored momentum; Kinetic charge; Time-locked object; Frozen impact build-up; 靜止蓄能; 時停蓄力; ビタロック; 運動エネルギー蓄積; 時止め蓄積

**Group:** Combat feedback & game feel
**Subcategory:** Time manipulation

## What you see

An object or enemy is locked in place — perfectly still and tinted — while the world around it keeps running. Hitting it does not move it; each hit only flashes it and grows a direction arrow whose colour climbs from yellow to orange to red, pointing along the accumulated force. The moment the stasis ends, the target is flung along the arrow, farther the more it was hit.

## Not to be confused with

Not hitstop (ACT-21 — both fighters pause a few frames on every hit). Not a plain freeze or stun (the target stops, but hits do not build into later motion). Not slow motion (FB-10 — the whole world slows). This card freezes one target, stores the hits, and releases them at once.

## Use it for

Puzzles (launching a boulder far away), crowd-control abilities, physics play built around charge-then-burst.

## Tunable parameters

stasis duration 4–8 s · tint colour · arrow length / colour thresholds · per-hit flash · end-warning blink 1 s · launch speed curve vs stored amount · max launch speed (authoring defaults)

## Request prompt

Add a stasis-with-stored-impact ability. The target is locked for 4–8 s: it holds position under a tint while everything else keeps running. Each hit flashes it once and adds the hit direction into a direction arrow that grows with the stored amount, colour going yellow → orange → red. Blink faster in the final second; at the end launch the target along the stored direction with speed rising with the stored amount. Accept: one hit versus many hits gives clearly different launch distances, and hits from different sides aim the arrow correctly.

## Implementation hint

Give the target its own time scale of 0 (or suspend its physics integration) while the rest of the world ticks. On each hit, add hitDirection × strength into a stored vector and flash; render an arrow along the stored vector with length and colour from its magnitude. On expiry restore the target's time scale and apply the stored vector as one clamped impulse, then clear it.
