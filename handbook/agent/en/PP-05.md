# PP-05 · Pixelation

**Aliases:** Mosaic; Pixelize; Pixelate filter; Censor mosaic

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

The image (or one region of it) is split into large squares, each a single colour, so detail disappears and only rough blocks and outlines remain; the block size can change.

## Not to be confused with

Not the pixelate transition (TRN-10, blocks grow then shrink to switch between two scenes); this is an ongoing filter state or a local censor. Not integer scaling (PIX-01, which just enlarges genuine pixel art).

## Use it for

Censoring, dizzy/poison states, low-res flashback shots, giving 3D a pixel look.

## Tunable parameters

block size · sample point (centre vs average) · region mask · grid alignment · ramp time

## Request prompt

Add a pixelation post-process to the game: sample in blocks of size B (one centre sample per block); B defaults to 1 (off), rises to 6 px over 0.25 s while the player is dazed and holds there; also provide a local mosaic that applies B=8 only inside a given rectangle (e.g. 48×48 px), with blocks aligned to screen coordinates so they don’t shimmer when things move.

## Implementation hint

Fullscreen pass: uvBlock = (floor(pixel/B)+0.5)*B/screenSize; sample source at uvBlock with point filtering. For an averaged mosaic, downsample to (W/B,H/B) with a box filter then upscale with nearest. Region mosaic = same pass with a scissor rect or mask.
