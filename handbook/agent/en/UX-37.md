# UX-37 · Onboarding / Interactive tutorial / Contextual teaching

**Group:** Visual guidance & wayfinding
**Subcategory:** Access Rules, Returning, and Learning

## What you see

You practice jumping somewhere safe, then use the same action at the next obstacle. Control reminders appear when needed, giving players opportunities to practice rather than merely read instructions.

## Not to be confused with

Onboarding is the broader introductory learning experience; tutorials are one means within it, not an exact synonym. An opening controls chart does not prove players can use those controls, and the absence of text does not automatically make teaching clear.

## Use it for

You practice jumping somewhere safe, then use the same action at the next obstacle. Control reminders appear when needed, giving players opportunities to practice rather than merely read instructions.

## Tunable parameters

safe practice · contextual prompt · repetition · application · mastery check · skip support

## Request prompt

Design jump onboarding with 1 control prompt in a no-fall area, 3 safe practice jumps, and a 1.5 m gap applying the action within 30 seconds; repeat the prompt only after 2 failures, and let experienced players skip text but not required ability grants.

## Implementation hint

Teach one action at a time through a safe prompt, immediate practice, and a later situation that reuses it with meaningful context. Observe successful use rather than assuming a displayed instruction was learned, and support returning or experienced players without removing essential knowledge.
