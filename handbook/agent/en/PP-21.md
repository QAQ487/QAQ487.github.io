# PP-21 · Gate weave / Film weave

**Aliases:** Gate weave; Film weave; Registration weave; 菲林畫格微晃; 膠片套準晃動; ゲートウィーブ; フィルムの揺れ; 画揺れ

**Group:** Post-processing & screen filters
**Subcategory:** Lens simulation

## What you see

A projected-film image subtly wanders inside an otherwise stationary frame. The recorded picture drifts as a flat plane, without camera parallax.

## Not to be confused with

PP-02 changes fine texture (grain). CAM-33 moves a viewpoint (breathing / handheld). PP-12 corrupts a digital signal. CAM-30 / FB-07 shake the camera or screen from events. Gate weave moves registration, not the virtual camera.

## Use it for

Archival cutaways, projected-film emulation, part of a memory package.

## Tunable parameters

amplitude (low) · irregularity · border/HUD lock · blend with grain (authoring defaults)

## Request prompt

Start archival-film presentation → picture inside a fixed border → introduce restrained irregular registration drift while the border and HUD remain still → settle to perfect registration when disabled.

## Implementation hint

Offset the colour buffer by a tiny 2D noise/wander each frame inside a fixed letterbox; do not move the gameplay camera. Keep HUD and frame matte untranslated.
