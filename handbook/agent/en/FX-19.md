# FX-19 · Loop / Start–Sustain–Stop

**Group:** Audio & haptics
**Subcategory:** Audio

## What you see

An engine, flame, or laser continues sounding and falls silent when the action stops. A fuller design separates start, sustain, and exit.

## Not to be confused with

Repeating a one-shot directly is not necessarily seamless. Seams, clicks, or abrupt changes should not be mistaken for intentional rhythm. Start–sustain–stop is a design breakdown, not a proprietary node name in a particular engine.

## Use it for

Express ongoing mechanical, environmental, or ability states.

## Tunable parameters

start segment · loop region · crossfade length · sustain gain · stop segment · release time · seam check

## Request prompt

Split a flamethrower into a 0.35-second start, a seamless 1.6-second sustain loop, and a 0.5-second stop; crossfade the loop seam over 40 ms and enter the stop segment within 60 ms of release without clicks.

## Implementation hint

Separate an ongoing sound into start, seamless sustain, and stop segments controlled by the activity state. Crossfade loop boundaries and route stop requests into a deliberate release rather than cutting the waveform abruptly.
