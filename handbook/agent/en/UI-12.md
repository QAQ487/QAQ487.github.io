# UI-12 · Tooltip

**Aliases:** Hover info; Info popup; Item tooltip; Mouse-over text; Item comparison; 裝備比較

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

When the cursor (or gamepad focus) rests on an item, skill or button for a moment, a small box appears beside it with the name, rarity colour, stats or a description, and disappears when the cursor leaves. Near the screen edge the box flips to the other side rather than being cut off. Comparison variant: show equipped vs candidate stats side by side with green/red deltas.

## Not to be confused with

Not a toast (UI-13, pushed by the system and self-dismissing); a tooltip appears only because the player points at something. Not a dialogue box (UI-16, story text).

## Use it for

Inventories, skill trees, shops, settings; detailed information without permanently taking screen space.

## Tunable parameters

hover delay · offset from cursor · edge flipping rule · fade time · max width & wrapping · rarity colours · gamepad anchoring

## Request prompt

Add item tooltips to your game’s inventory: after the cursor rests on a slot for 0.35 s, fade in over 0.1 s a dark box (#141a24, 90% opaque, 1 px border in the rarity colour) 8 px below-right of the cursor; first line is the item name in the rarity colour, then two grey stat lines; if an item of the same slot is equipped, show deltas beside them (↑ green / ↓ red). If the box would leave the screen on the right or bottom, flip it; when moving to another slot, swap content immediately without waiting for the delay again.

## Implementation hint

Measure the text first, then position: x = cursor.x + offset; if x + w > screenW, x = cursor.x - offset - w (same for y). Draw with a 9-slice panel (UI-14) on the topmost UI layer. Track a "tooltip already open" flag so moving between slots skips the delay.
