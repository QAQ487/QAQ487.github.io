# UI-14 · Nine-slice / 9-patch

**Aliases:** 9-slice scaling; Nine-patch; Scale-9 grid; Border image

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

One small panel image can be stretched into dialogue boxes, buttons or windows of any size while the decorated corners stay exactly as drawn; only the four edges extend along one axis and the centre fills the rest.

## Not to be confused with

Not scaling the whole image (corners and borders get stretched and blurry); nine-slice cuts the image into a 3×3 grid and treats each part separately. Not a tilemap (PIX-17, building scenes out of many tiles).

## Use it for

Every UI frame whose size varies: dialogue boxes, buttons, tooltips, inventory panels; one asset covers all sizes and pixel-art borders stay crisp.

## Tunable parameters

margins (left/top/right/bottom) · stretch vs tile for edges & centre · pixel scale · minimum size · content padding

## Request prompt

Draw every panel in your game’s UI with nine-slice: a 24×24 px source with 8 px margins on each side as corners; draw corners at native size, top/bottom edges stretch horizontally only, left/right edges vertically only, and the centre in both; for pixel art tile (repeat) the edges instead of stretching them, scale by whole integers and sample nearest-neighbour.

## Implementation hint

Emit 9 quads (or 16 vertices / 54 indices) whose positions use the target size and whose UVs use the fixed source margins; for tiled edges either emit repeated quads or use a wrap sampler with UVs scaled by (edgeLength / sourceEdgeLength). Keep vertex positions on integer pixels.
