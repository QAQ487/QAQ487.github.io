# FB-25 · Weapon-model recoil and return

**Aliases:** Viewmodel recoil; Animated recoil; Gun kickback; Recoil recovery; 槍模後座; ビューモデル反動

**Group:** Combat feedback & game feel
**Subcategory:** Aiming & handling

## What you see

The weapon snaps in the hands then mechanically returns to ready, with a stationary camera if desired. Whether aim point climbs is a separately declared ballistic policy — not implied by the visual.

## Not to be confused with

Not camera kick (FB-08) and not locomotion sway (FB-22). This is the firing viewmodel layer.

## Use it for

FPS gunfeel, shots that must kick in the hands.

## Tunable parameters

pitch impulse · back translate · return time · settle · stack cap · interrupt on reload/swap (authoring defaults)

## Request prompt

On an actual shot: fast pitch + backward impulse on the weapon/hand visual layer, slightly delayed translation, then controlled return with a small settle to neutral relative to current aim/locomotion pose. Repeated shots accumulate within a cap; reload or weapon switch interrupts. Keep ballistic recoil policy explicit and separate.

## Implementation hint

OnFire: add impulses to viewmodel spring (rot + pos). Integrate damped spring toward pose driven by aim+locomotion. Clamp stacked kick. Camera kick (FB-08) and spread (FB-19) are optional parallel systems — do not entangle their parameters silently.
