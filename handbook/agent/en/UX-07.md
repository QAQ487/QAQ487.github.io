# UX-07 · Menu navigation / Focus order；Tabs

**Aliases:** Menu hierarchy; Focus order; 選單位置; メニュー階層

**Group:** UI & HUD
**Subcategory:** On-screen Information and Menus

## What you see

Tabs, focus order and back rules carry the player through menus; show the page title and category so deep stacks stay oriented. Restore tab, focus and scroll on return.

## Not to be confused with

Do not assume path memory; every route must work without a pointer.

## Use it for

Tabs, focus order and back rules carry the player through menus; show the page title and category so deep stacks stay oriented. Restore tab, focus and scroll on return.

## Tunable parameters

tab order · page title · category crumb · directional neighbors · confirm · back · wrapping · focus & scroll memory

## Request prompt

Build Equipment / Map / Skills tabs with a page title and category crumb (e.g. Menu › Equipment). Shoulder buttons change tabs; directions move to visual neighbours without wrapping at grid edges; returning from a child page restores tab, focus and scroll.

## Implementation hint

Show the current page name and its category so deep menus stay oriented. Define directional neighbors for grids and a stable order for lists. Preserve per-tab focus and scroll on back; keep confirm/back consistent across pages.
