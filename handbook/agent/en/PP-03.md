# PP-03 · CRT filter

**Aliases:** CRT shader; Scanlines; Shadow mask / Aperture grille; CRT emulation

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

Horizontal dark lines (scanlines) run across the image; up close there is a red-green-blue stripe or dot mask, the edges bow outward slightly, the corners darken, highlights bleed a little glow, sometimes a slow bright band rolls upward.

## Not to be confused with

Not film grain (PP-02, random noise) nor integer scaling (PIX-01, which only enlarges pixels cleanly). A CRT filter simulates the display structure of an old TV after upscaling.

## Use it for

Retro mood, making low-res pixel art look as it did on old TVs, a “retro mode” toggle in options.

## Tunable parameters

scanline strength & profile · mask type (aperture grille / shadow mask / slot) · curvature · bloom/glow · corner radius · rolling band

## Request prompt

Add a CRT filter option to the game: integer-upscale first, then darken the bottom 1/3 of each source pixel row to 60%; overlay an RGB vertical-stripe mask (3 output pixels per triad, strength 0.15); barrel curvature 0.04; corner vignette 0.3; every 6 s a 20 px tall band of +4% brightness rolls from bottom to top. Toggleable in settings.

## Implementation hint

Render the game to a low-res target, then a fullscreen pass at output res: warp uv for curvature; sample source (nearest or sharp-bilinear); scan = lerp(1, minScan, f(frac(uv.y*srcH))); mask = triad colour by (pixel.x % 3); out = src*scan*mask, plus a blurred bright-pass added for glow.
