# UX-14 · Meta UI

**Group:** UI & HUD
**Subcategory:** Where the Interface Lives

## What you see

Blood around the screen edges conveys injury. The state relates to the character’s experience, but is not a physical interface in the scene that you can approach.

## Not to be confused with

“Meta” here does not mean the metagame, popular builds, or breaking the fourth wall. Classification allows room for interpretation; do not force every red filter into one supposedly definitive category.

## Use it for

Blood around the screen edges conveys injury. The state relates to the character’s experience, but is not a physical interface in the scene that you can approach.

## Tunable parameters

injury intensity · screen edge · status mapping · fade timing · accessibility · competing effects

## Request prompt

Design injury meta UI where edge grime rises from 10% to 35% opacity as health drops from 40% to 15%, then fades over 1.5 seconds after recovery; never obscure the central 60% and offer 0, 50, and 100% intensity settings.

## Implementation hint

Drive screen effects from the character state with bounded intensity and a clear recovery curve. Keep essential scene and interface details visible, offer intensity controls, and avoid classifying every stylized overlay as the same narrative device.
