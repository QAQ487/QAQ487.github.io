# UI-21 · Hotbar / action bar

**Aliases:** 快捷欄; 畫面底一排道具格; 按 1 至 9 換工具; Hotbar; Action bar; Quick slots; ホットバー; アクションバー; クイックスロット

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

A row of quick-use tool or skill slots along the bottom (or a corner): each shows icon, hotkey and count; a thick frame marks the equipped slot, empty slots keep their place, and cooldowns count down inside the cell. Switching updates the highlight immediately; empties do not collapse. Roughly, hotbar ≈ item slots and action bar ≈ skills; compare beside a radial menu (UI-11).

## Not to be confused with

Not a radial menu (UI-11, direction pick) and not a full grid inventory (UI-22). A hotbar is a persistent, small, immediately actionable strip.

## Use it for

Sandbox tool switching, MMO skill rows, quick consumables.

## Tunable parameters

slot count · icon size · hotkey glyphs · stack count · equipped frame · empty reservation · cooldown numeral · bottom-centre vs corner anchor · safe-area margin

## Request prompt

Line up quick-use tools. Each slot shows icon, hotkey and count. Mark the equipped slot with a thick frame, keep empty slots, and show cooldown numbers inside cells. Build both bottom-centre and corner layouts and check they do not cover critical play space.

## Implementation hint

Keep a fixed array of N slot rects; never delete empties—draw an empty frame. Equipped index drives a thicker border. Bind keys 1..N and gamepad shoulder+face for cycle. Reuse cooldown wedge/number from UI-05 inside the cell. Re-anchor within safe area (UI-25) on resolution change.
