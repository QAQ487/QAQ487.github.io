# UX-08 · Modal dialog

**Aliases:** Focus containment; Modal focus trap; 模態焦點; フォーカストラップ; Zone confirm; Point of no return prompt; 跨區確認; 離開確認

**Group:** UI & HUD
**Subcategory:** On-screen Information and Menus

## What you see

A modal dialog is an interaction mode in which you must deal with the dialog before interacting with the content behind it. Focus containment is the mechanism that keeps focus inside the dialog; these are not synonyms. “Focus trap” sometimes refers to this containment, but can also describe a broken focus trap that cannot be exited normally. A proper design should provide clear confirm/cancel controls or another appropriate way out. “Are you sure you want to delete this save?” covers the original menu, with focus remaining inside the dialog; you must confirm or cancel before continuing.

## Not to be confused with

Not everything that pops up is modal; a corner notification may be non-modal. Blocking input with a modal dialog does not mean the game world has paused.

## Use it for

“Are you sure you want to delete this save?” covers the original menu, with focus remaining inside the dialog; you must confirm or cancel before continuing. Before entering an area the player cannot return from, the same modal can list unfinished side goals and wait for confirm or cancel. The dialog is the prompt; which areas become unreachable is a traversal rule and is not this entry. (The zone-confirm fragment of former entry UX-35 is merged here; the collapse behind the player is VFX-18.)

## Tunable parameters

blocking state · initial focus · focus containment · confirm · cancel · press vs disabled · background input · focus restore

## Request prompt

Build a delete-save modal with Cancel / Delete; start focus on Cancel and keep Tab inside. Delete may show a press squash; if the save is protected, Delete is disabled with a lock and reason. On Escape restore save 3, or the nearest enabled save if it was removed.

## Implementation hint

Trap focus inside the modal, start on a safe action, and restore the previous outside focus on close (nearest enabled if gone). Show pressed and disabled distinctly on modal buttons. Do not assume the world is paused.
