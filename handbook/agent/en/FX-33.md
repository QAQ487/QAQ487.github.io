# FX-33 · Haptic Pattern / Event Identity

**Group:** Audio & haptics
**Subcategory:** Haptics, Accessibility, and Cross-sensory Information

## What you see

Some events use one short pulse, others an intermittent rhythm or sustained vibration. Recognize the pattern’s rhythm, not only its strength.

## Not to be confused with

Distinguishable patterns are not necessarily suitable as the only signal. Overlapping events may mask one another. This entry extends the principle of additional information channels into a design recommendation; it does not claim that XAG prescribes a particular vibration code.

## Use it for

Establish learnable tactile differences between events. This chapter recommends testing hit, warning, and other patterns separately rather than assuming everyone can distinguish them.

## Tunable parameters

pulse count · pulse duration · interval · amplitude profile · pattern length · overlap priority · recognition test

## Request prompt

Define three haptic patterns: one 60 ms pulse for a hit, three 80 ms pulses separated by 120 ms for a warning, and one 150 ms pulse every 500 ms for ongoing damage; test recognition with 12 participants and never use vibration as the sole cue.

## Implementation hint

Assign events distinct temporal envelopes rather than differentiating them only by strength. Resolve overlaps by priority or blending, and validate recognition with users while retaining non-haptic cues.
