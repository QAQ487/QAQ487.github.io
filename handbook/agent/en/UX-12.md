# UX-12 · Non-diegetic UI / Overlay UI

**Group:** UI & HUD
**Subcategory:** Where the Interface Lives

## What you see

Numeric health in a screen corner or inventory slots need no story-world explanation for how the character sees them.

## Not to be confused with

Matching the setting’s visual style does not make an interface diegetic; an old-paper-style menu can still exist only for the player. Overlay is a presentation method, not necessarily a complete determination of narrative classification.

## Use it for

Numeric health in a screen corner or inventory slots need no story-world explanation for how the character sees them.

## Tunable parameters

player-only data · screen anchor · inventory slots · health value · visual theme · visibility

## Request prompt

Create a player-only overlay with 73/100 health fixed at top left and an 8-slot quick bar at the bottom; keep positions stable as the camera turns, and use an old-paper style without implying the character literally sees these values.

## Implementation hint

Render player-only information in a screen-anchored layer independent of world objects. It may share the setting’s visual language, but its visibility and behavior should be governed by player information needs rather than fictional-world access.
