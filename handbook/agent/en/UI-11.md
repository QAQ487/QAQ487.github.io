# UI-11 · Radial menu

**Aliases:** Pie menu; Weapon wheel; Ring menu; Radial selector; Quick chat wheel; Communication wheel; 快捷聊天輪盤; 通訊輪盤

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

While a button is held, options are arranged in a circle around a centre (often 4–8 wedges); the stick or mouse direction picks a wedge, which grows or brightens, with its name in the middle; releasing the button confirms and closes the menu. Common variants include tool/weapon rings and multiplayer quick-chat wheels: hold, pick a phrase by direction, release to send, give the same phrase a short cooldown, and show it in the chat log with an optional bark. (Former entry UI-18, “Quick-chat wheel”, is merged here.)

## Not to be confused with

Not a regular list menu (moving focus up and down in order); a radial menu selects by direction, not sequence. Not a cooldown sweep (UI-05, where a wedge shows time).

## Use it for

Gamepad weapon/tool rings, quick emotes, build categories, multiplayer quick chat; each option is one direction away, so muscle memory makes it fast.

## Tunable parameters

wedge count · radii · dead zone · open/close timing · time scale while open · hold vs toggle · selection highlight

## Request prompt

Add an item radial menu to your game: while Q or LB is held, 8 wedges expand from 60% to 100% with ease-out back over 0.12 s, outer radius 40 px, inner radius 14 px, and gameplay slows to 30%; select by stick or mouse direction with an 8 px dead zone; the selected wedge brightens and moves out 3 px with the item name in the centre; releasing confirms and closes over 0.08 s.

## Implementation hint

index = floor(((atan2(dy,dx) + π/2 + π/n) mod 2π) / (2π/n)) after checking |d| > deadzone. Build wedges as triangle-strip arcs (or one quad with an angle/radius test in the pixel shader). Remember the last selection so a quick tap can re-use it.
