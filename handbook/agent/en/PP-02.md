# PP-02 · Film grain

**Aliases:** Grain; Noise overlay; Film noise

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

A fine random speckle that changes every frame covers the whole image, most visible in shadows and mid-tones; even a still shot seems to gently “boil”.

## Not to be confused with

Not dithering (PIX-08, a fixed regular pattern that doesn’t jump each frame) nor a CRT filter (PP-03, regular scanlines). Grain is random, refreshed every frame and fullscreen.

## Use it for

Film or documentary texture, horror mood, vintage-photo feel; also breaks up gradient banding.

## Tunable parameters

intensity · grain size · luminance response · colour vs mono · update rate

## Request prompt

Add a film-grain post-process to the game: generate monochrome noise with a new seed each frame, grain size 1 px at output resolution, intensity 0.06, weighted toward mid-tones by 4·L·(1−L) so pure black and white are barely touched; refresh the grain pattern at 24 fps rather than every display frame.

## Implementation hint

Fullscreen pass: n = hash(pixelCoord + frameSeed) - 0.5 (or sample a tiling noise texture with a per-frame random UV offset); w = 4*L*(1-L); out = src + n*intensity*w. Apply after tonemapping so grain is in display space.
