# UX-39 · Low-durability warning

**Aliases:** 耐久度警告; 裝備快壞; Break warning; Low durability flash

**Group:** UI & HUD
**Subcategory:** Resources & status

## What you see

When a weapon or tool is near breaking, its icon cracks, recolours or pulses, sometimes with a fatigue animation or cue, giving time to swap before it breaks.

## Not to be confused with

Not the UX-02 meter itself; this is a “about to break” status warning. Can sit beside UX-02.

## Use it for

Action RPGs and survival crafters with durability.

## Tunable parameters

warn thresholds · pulse period · crack overlay · break FX · reduced-flash option (starting points)

## Request prompt

Below 20% durability pulse the icon red every 0.8 s with a crack overlay; below 5% keep a red frame. On break play one shatter and remove from the hotbar. Offer a no-blink mode that uses cracks only.

## Implementation hint

if dur/max < tWarn: icon.pulse=true; if < tCritical: icon.holdWarn=true; on 0: Break().
