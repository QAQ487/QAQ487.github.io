# UX-11 · Diegetic UI / In-world interface

**Group:** UI & HUD
**Subcategory:** Where the Interface Lives

## What you see

A character checks a watch for remaining resources or operates a wall terminal. The information belongs to the story world, rather than existing only for the player.

## Not to be confused with

Does looking three-dimensional make something diegetic? No: ask whether its existence is acknowledged within the character’s world. In-world interfaces can also be hard to read or slow to use; they are not inherently better.

## Use it for

A character checks a watch for remaining resources or operates a wall terminal. The information belongs to the story world, rather than existing only for the player.

## Tunable parameters

world ownership · character access · physical placement · legibility · interaction distance · fallback

## Request prompt

Design an in-world oxygen watch showing 0–100% and 12:30 remaining, readable after a 0.4-second raise-hand action; add a high-contrast mode for bright light and have the watch itself warn below 15%.

## Implementation hint

Anchor the interface to an object acknowledged by the fictional world and let character actions operate it. Preserve readability across viewing distances and provide a fallback when perspective, lighting, or occlusion makes the in-world surface unusable.
