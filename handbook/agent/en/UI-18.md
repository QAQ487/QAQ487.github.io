# UI-18 · Quick-chat wheel (multiplayer)

**Aliases:** 快捷聊天輪盤; 通訊輪盤; Quick chat wheel; Communication wheel; クイックチャット

**Group:** UI & HUD
**Subcategory:** Interaction cues

## What you see

Hold a comms button to open a wheel of phrases (“on me”, “need ammo”, “thanks”); release to send into chat and optional voice barks.

## Not to be confused with

Specializes UI-11 radial menus for multiplayer lines; projects with one generic wheel may only enrich UI-11. This ID exists when comms need their own card.

## Use it for

Pad-only multiplayer; racers/shooters that need fast callouts.

## Tunable parameters

phrase set · cooldown · hold vs toggle · log + optional bark (starting points)

## Request prompt

Hold to open 6–8 wedges; sending closes in 0.1 s; 2 s cooldown per phrase. Separate bind from NAV-14 ping.

## Implementation hint

Reuse radial selection from UI-11; OnConfirm: Broadcast(phraseId); StartCooldown(phraseId).
