# UX-20 · Reduced motion / Motion settings

**Group:** UI & HUD
**Subcategory:** Motion and Interaction Feedback

## What you see

Disabling animated menu backgrounds, reducing camera shake/head bob, or stopping automatic scrolling helps players concentrate on reading information clearly.

## Not to be confused with

This is not a low-graphics-quality mode, nor does it necessarily remove all in-game movement. Focus on nonessential motion, camera effects, and reading burden.

## Use it for

Disabling animated menu backgrounds, reducing camera shake/head bob, or stopping automatic scrolling helps players concentrate on reading information clearly.

## Tunable parameters

camera shake · head bob · menu motion · auto-scroll · flashing · intensity preset

## Request prompt

Add reduced-motion settings for 0–100% camera shake, head bob, animated menu backgrounds, and auto-scroll; the preset should set shake to 10%, disable bob and sliding, and preserve the same 6 functions and clear focus.

## Implementation hint

Expose independent controls for nonessential camera, interface, scrolling, and flashing effects, plus a convenient reduced-motion preset. Replace large movement with stable state changes while retaining all information and actions.
