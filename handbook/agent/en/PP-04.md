# PP-04 · Posterization

**Aliases:** Color quantization; Posterize; Tone banding

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

Smooth gradients (sky, glows, shadows) break into a few visible colour steps; the image looks like a print or poster, with fewer colours but the original hues kept.

## Not to be confused with

Not a limited palette (PIX-10, where the artist paints with fixed colours from the start); posterization quantizes each channel of a finished image after the fact. Not dithering (PIX-08, which fakes in-between colours with patterns).

## Use it for

Poster/comic styles, a retro-console colour feel, poison or hallucination status effects, deliberate lo-fi looks.

## Tunable parameters

levels per channel · per-channel vs luminance quantization · dither before quantize · colour space (gamma vs linear)

## Request prompt

Add a posterization post-process to the game: quantize each RGB channel to N levels (default 5, range 2–16) with floor(c·(N−1)+0.5)/(N−1); optionally add a 4×4 Bayer dither offset (strength 1/N) before quantizing to soften hard bands; when a status effect triggers, drop from 16 to 4 levels over 0.3 s.

## Implementation hint

Fullscreen pass in display (gamma) space: c = floor(c*(N-1) + 0.5 + ditherOffset)/(N-1). Quantizing luminance only (then re-applying chroma) keeps hues steadier than per-channel quantization.
