# UX-03 · Reticle / Crosshair

**Group:** UI & HUD
**Subcategory:** On-screen Information and Menus

## What you see

A dot, ring, or cross in the center of the screen provides an aiming reference; some designs change size to indicate state. Search `reticle crosshair UI`.

## Not to be confused with

The reticle’s position does not guarantee a hit or an exact match with the weapon’s actual trajectory. Distinguish the displayed cue from the hit-detection rules.

## Use it for

A dot, ring, or cross in the center of the screen provides an aiming reference; some designs change size to indicate state. Search `reticle crosshair UI`.

## Tunable parameters

center point · spread radius · weapon state · target feedback · trajectory offset · contrast

## Request prompt

Design a reticle with a 6 px radius while still, expanding to 18 px while moving and becoming dashed during reload; add a separate impact cue for projectile drop at 20 m without implying a guaranteed hit.

## Implementation hint

Render the reticle as an aiming reference driven by weapon spread and interaction state, while leaving hit resolution to gameplay rules. If projectile drop or offset matters, communicate uncertainty rather than promising an exact impact point.
