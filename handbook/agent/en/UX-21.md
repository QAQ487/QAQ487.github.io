# UX-21 · Affordance / Action possibility

**Group:** Visual guidance & wayfinding
**Subcategory:** Spatial Recognition and Guidance

## What you see

A low wall within the character’s jumping capability that can actually be vaulted, or a ladder that can actually be climbed, represents an action possibility arising between the character’s abilities and the environment/rules.

## Not to be confused with

Yellow paint telling you something is climbable is primarily a signifier. Whether you can climb it and whether cues tell you so are separate questions. Perceived affordance is another common search term, but should not obscure this distinction.

## Use it for

A low wall within the character’s jumping capability that can actually be vaulted, or a ladder that can actually be climbed, represents an action possibility arising between the character’s abilities and the environment/rules.

## Tunable parameters

actor capability · object property · rule check · action range · state change · failure reason

## Request prompt

Define vault affordance for a character with a 1.2 m jump: only walls 0.4–1.0 m high with 0.6 m overhead clearance are vaultable; block the action above 30 kg carried weight and report why, regardless of yellow paint.

## Implementation hint

Compute affordance from the relationship between actor capabilities, object properties, and current rules. Expose a consistent action result and a useful failure reason, while leaving visual communication of that possibility to separate signifiers.
