# UX-15 · World-space UI / Screen-space UI

**Group:** UI & HUD
**Subcategory:** Where the Interface Lives

## What you see

A wall panel that shrinks with perspective and can be blocked by objects is a typical world-space example; an interface fixed to the screen is typically screen-space. Search `world space screen space UI`.

## Not to be confused with

A health bar following an enemy’s head is not necessarily a world mesh; a 3D point can be projected into 2D before drawing it. World-space certainly does not automatically mean diegetic.

## Use it for

A wall panel that shrinks with perspective and can be blocked by objects is a typical world-space example; an interface fixed to the screen is typically screen-space. Search `world space screen space UI`.

## Tunable parameters

coordinate space · perspective · occlusion · projection · screen anchor · distance

## Request prompt

Implement 2 interface spaces: a 1-by-0.6 m wall panel that scales with perspective and can be occluded by a pillar, and an objective card fixed 32 px from the top-right edge; project enemy head positions into 2D for health bars without calling them diegetic.

## Implementation hint

Choose world or screen coordinates according to the desired perspective, occlusion, and stability. A world-following cue may still be projected and drawn in screen space, so keep coordinate implementation separate from diegetic classification.
