# FX-18 · One-shot

**Group:** Audio & haptics
**Subcategory:** Audio

## What you see

One button press produces one gunshot or collision sound, which ends naturally without requiring the trigger to remain active.

## Not to be confused with

Repeatedly triggered short sounds may resemble a loop. A one-shot can still have a long reverb tail; its file is not necessarily short.

## Use it for

Communicate discrete events such as landing, hitting, and confirmation.

## Tunable parameters

trigger event · retrigger rule · attack time · tail duration · concurrency limit · cooldown · stop behavior

## Request prompt

Trigger one one-shot per landing, start it within 20 ms of contact, use a roughly 0.25-second body with up to a 1.2-second reverb tail, and allow no more than two overlapping landing sounds per character.

## Implementation hint

Trigger the sound once per discrete event and allow it to complete without a held input. Define retrigger and concurrency behavior so rapid events remain intelligible even when one-shots overlap.
