# UI-20 · Iconography / UI icon family

**Aliases:** 介面圖示語言; 圓角圖案一套; 背包圖示家族; UI icon set; Icon family; Consistent glyphs; アイコン体系; UIアイコンセット

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

Map, bag, quest and settings icons share frame ratio, stroke weight and corner radius, yet each keeps a distinct silhouette. New-content badges sit in one shared corner; first appearance may include a text label. At in-game size they remain distinguishable without relying on colour.

## Not to be confused with

Not single-button states (UI-03) and not cooldown sweeps (UI-05). This entry is about family consistency and recognition across a set.

## Use it for

In-game phone apps, bottom bars, system icons, functional glyphs beyond rarity pips.

## Tunable parameters

frame size · stroke weight · corner radius · silhouette vocabulary · badge corner · first-run label · colour-blind check · min display size

## Request prompt

Draw a set of map, bag, quest and settings icons. Keep shared frame ratio, stroke weight and corners, with a different main silhouette each; mark new content in one shared spot and add text on first show. Check recognition at the real in-game size.

## Implementation hint

Author icons on a shared grid (e.g. 24×24 with 2 px padding). Prefer shape over hue; test greyscale and 12–16 px downscales. Store a family style sheet (stroke, radius, fill rules) so new icons match. Badge new content with one reserved corner rect.
