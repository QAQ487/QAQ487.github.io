# UI-26 · HUD edit mode

**Aliases:** 可編輯 HUD; 自己拖技能列同小地圖; Edit Mode; Custom HUD layout; ドラッグ配置HUD

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

Edit mode lets players drag, scale and snap HUD widgets, save a layout and restore defaults in one action. After resolution or safe-area changes, widgets re-clamp into view. Play mode locks positions to avoid accidental drags.

## Not to be confused with

Not contextual show/hide (UI-24) and not a mere reskin. This entry is player-authored placement and scale.

## Use it for

MMOs, sims, titles that need accessible custom layouts.

## Tunable parameters

drag · scale handles · snap grid · save slots · reset default · play-mode lock · reclamp on resize · per-widget constraints

## Request prompt

In edit mode allow drag, scale and snap, save layouts and restore defaults; after resolution changes re-clamp into the safe area.

## Implementation hint

Enter edit mode from settings: draw drag handles and a snap grid. Persist {id, anchor, normOffset, scale} per widget. On load and on resize, run clampToSafe(UI-25). Reset writes factory layout. Disable hit-testing of gameplay while editing.
