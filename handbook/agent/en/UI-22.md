# UI-22 · Spatial inventory / grid inventory

**Aliases:** 多格背包; 支槍佔幾格; 執背包砌積木; Grid inventory; Tetris inventory; Multi-cell items; グリッドインベントリ; 空間インベントリ

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

Items can occupy several cells: while dragging, preview the footprint, update it after rotate, mark conflicts on overlap or out-of-bounds, and keep the origin on failed drop. A contrasting mode uses one cell per item.

## Not to be confused with

Not a hotbar (UI-21) and not world placement ghosts (NAV-05). This is in-bag footprints and rotation.

## Use it for

Survival/horror pack management, weapon-mod space, RPGs that want packing pressure.

## Tunable parameters

cell size · item footprints · rotate 90° · ghost preview tint · conflict tint · snap · one-cell mode · cancel restores origin

## Request prompt

Items may span multiple cells. Preview the footprint while moving, update after rotate, mark conflicts on overlap or out-of-bounds, and keep the origin on failed drop. Also draw a one-cell-per-item variant for contrast.

## Implementation hint

Represent the bag as a boolean occupancy grid. On drag, stamp the item mask at the hovered origin; valid = all cells free and in bounds. Rotate remaps the mask. On reject, tween the icon back and flash conflict cells (pair with UI-04). Offer a toggle that collapses every item to 1×1 for accessibility or casual modes.
