# UI-02 · Number roll / Count-up

**Aliases:** Counting number; Rolling counter; Odometer counter; Score tally

**Group:** UI & HUD
**Subcategory:** UI motion

## What you see

When score, money or XP rises, the number does not jump to the new value: it rapidly counts up over 0.5–1 s (usually fast then slow) and gives a small scale pop on arrival. There is also an odometer version where each digit scrolls vertically.

## Not to be confused with

Not damage numbers (FB-02, one-off values that float out in the world and vanish); a number roll is a HUD total changing in place. Not a combo counter (FB-18, which counts consecutive hits).

## Use it for

Results screens, money/score HUDs, the balance after a shop purchase; lets the player feel how much they gained, not just see the result.

## Tunable parameters

duration (fixed or scaled by delta) · easing · tick sound rate · arrival pop scale · colour while rolling · odometer vs plain digits

## Request prompt

Add a number roll to the money HUD in your game: on every increase count from the old to the new value over 0.6 s with ease-out cubic (1.0 s if the difference exceeds 1000); on arrival scale the whole number to 115% and back over 0.12 s; tint it gold #f2c94c while rolling and white afterwards. If more income arrives mid-roll, continue from the currently displayed value to the new total.

## Implementation hint

Store displayValue separately from the real value; each frame displayValue = lerp(from, to, ease(k)) and print floor(displayValue). For the odometer, draw each digit column from a vertical digit strip with a scissor/clip rect and offset by the fractional part of (value / 10^place). Throttle tick sounds to ≤ 20 per second.
