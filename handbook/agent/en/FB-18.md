# FB-18 · Combo counter

**Aliases:** Hit counter; Chain counter

**Group:** Combat feedback & game feel
**Subcategory:** UI feedback

## What you see

During consecutive hits a fixed spot on screen shows something like "12 HITS"; it bounces bigger on every increment and has a shrinking timer bar; when broken the number fades or a grade is tallied.

## Not to be confused with

Not damage numbers (FB-02, which follow targets and show damage); a combo counter shows a count and lives in the HUD.

## Use it for

Encourages keeping up the pressure and builds rhythm; can tie into score multipliers.

## Tunable parameters

combo window (s) · bump scale · timer bar · colour tiers · break animation · score multiplier

## Request prompt

Add a combo counter to the game: show "N HITS" at the top right, scale the number to 130% and back over 0.1 s on each hit, with a 2 s timer bar underneath; reset and fade out over 0.3 s if no hit lands in 2 s; turn the number gold from 10 hits.

## Implementation hint

UI batch with a bitmap font; scale anim from a per-element timer. Keep the combo window logic in gameplay code and expose it to the UI as (count, timeLeft/window).
