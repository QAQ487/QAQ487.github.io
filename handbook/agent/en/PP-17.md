# PP-17 · Cross-processing / X-pro

**Aliases:** Cross-processing; X-pro; Cross-processed look; 交叉沖洗; 正片負沖; クロスプロセス; クロス現像

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

Punchy, chemically “wrong” colour, with conspicuous casts and differently shifted shadows and highlights (a common teaching example is green-cyan shadows with yellow highlights). Results vary; there is no single universally correct green cross-process preset — say so on the card.

## Not to be confused with

REN-32 is the umbrella grade. CIN-14 is memory/flashback. This is a named photographic family rather than a generic LUT or a flashback package.

## Use it for

Retro photography, music-video colour, deliberately wrong colour.

## Tunable parameters

shadow tint · highlight tint · contrast · preset label (example, not universal) · HUD exclude (authoring defaults)

## Request prompt

Enable cross-processed treatment → scene image → introduce an explicit example such as green-cyan shadows and yellow highlights, with strong contrast and unusual colour relationships → clean restoration on disable.

## Implementation hint

Split-tone after tonemap: push shadows toward green-cyan and highlights toward yellow (one authored example), raise contrast. Document that other chemical looks exist; expose a preset name rather than claiming one true curve.
