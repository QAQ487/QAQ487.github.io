# FX-21 · Parameter-driven Audio

**Group:** Audio & haptics
**Subcategory:** Audio

## What you see

As vehicle speed increases, pitch or the balance of engine layers changes continuously rather than switching abruptly at each state.

## Not to be confused with

A pitch change is not necessarily time-stretching. Engine sound may crossfade between several recordings rather than simply modify one track.

## Use it for

Turn continuous values such as speed, charge, and pressure into audible information.

## Tunable parameters

input parameter · normalization range · layer crossfade · pitch curve · smoothing time · update rate · fallback state

## Request prompt

Map vehicle speed from 0–180 km/h across three engine recordings covering 0–60, 40–120, and 100–180 km/h; update the parameter 30 times per second and smooth it over 120 ms to avoid abrupt RPM changes.

## Implementation hint

Map a normalized gameplay value to continuous gain, filter, or pitch curves and smooth incoming changes. Crossfade multiple recordings where one source cannot cover the full range naturally.
