# A11Y-06 · High-contrast solid silhouette mode

**Aliases:** 看不清敵人; 高對比模式; 把重要物件塗成純色; High-contrast mode; Solid silhouette mode; Simplified visuals; Contrast mode; ハイコントラストモード

**Group:** Readability & accessibility
**Subcategory:** Visual modes & comfort

## What you see

When enabled, the background is darkened and desaturated while players, enemies, interactables and hazards are each filled with one high-contrast solid colour, forming clear silhouettes. Detail drops sharply, but what matters and where it is becomes obvious at a glance — especially helpful for low-vision players, attention needs or small screens. The colour categories should be customisable.

## Not to be confused with

Not an X-ray silhouette (MATX-10, which outlines only when occluded), not an interactable highlight (NAV-01, marking individual objects) and not sound visualisation (FX-36). This is a whole-screen mode switch that recategorises and recolours the entire scene.

## Use it for

Accessibility options in action and shooting games, low-vision players, cluttered or effect-heavy scenes, small handheld screens.

## Tunable parameters

environment brightness 20–40% · greyscale on · category colours (player/enemy/interactable/hazard) · outline 1–3 px · particle scale 0.2–0.5 (starting points)

## Request prompt

Add a high-contrast mode: when on, render the environment in greyscale darkened to 30% brightness, and fill the player in blue, enemies in red, interactables in yellow and hazards in magenta (each category customisable in settings), each with a 2 px dark outline (all starting values). Reduce effect particles to 30% of normal. Use colour-vision-deficiency simulation to check every category stays distinguishable for all three types (see A11Y-03).

## Implementation hint

Tag renderers with a semantic category; in high-contrast mode render environment through a greyscale×dim post step, then draw tagged objects with an unlit solid-colour override plus an outline pass (NPR-03). Category colours come from the same token table as A11Y-03 so CVD presets apply.
