# UI-19 · Retro-futuristic terminal / CRT UI

**Aliases:** 青綠色飛船電腦; 舊式單色屏幕; 掃描線終端; CRT terminal; Monochrome HUD; Sci-fi CRT UI; レトロ未来端末; CRT風UI; モノクロ端末

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

The screen reads like an old monochrome ship computer: fixed title, readouts and action zones built from thin frames, monospace digits, ticks and terse abbreviations. Soft scanlines may sit behind sharp text. With motion off, the terminal composition must still read clearly.

## Not to be confused with

Not diegetic UI itself (UX-11, information living on a fiction object); this entry is the industrial-terminal look for overlays and menus. Not screen glitch (PP-12) or pause blur (UI-07). The same options can contrast a themed collage pause menu.

## Use it for

Sci-fi HUDs, ship/lab computers, hacking screens, industrial pause and settings pages.

## Tunable parameters

title band · readout columns · monospace digits · tick marks · abbreviations · scanline opacity · reduced-motion static · accent colour (cyan/amber)

## Request prompt

Build a cyan monochrome ship terminal. Fix the title, readouts and action zones; use thin frames, monospace digits, ticks and short abbreviations for an instrument feel. Add low-intensity scanlines behind sharp text; show a static version when motion is disabled.

## Implementation hint

Composite a full-screen UI layer: solid dark panel, 1 px frames, monospace labels. Draw scanlines as a repeating 1–2 px translucent band on a separate layer behind glyphs (never blur the text). Keep interactive rows selectable with the same focus rules as other menus. Provide a static frame when reduced-motion is on.
