# UX-16 · UI motion / UI transition / Animated focus

**Aliases:** Push-pop transition; Menu hierarchy motion; 換頁過渡; プッシュポップ遷移

**Group:** UI & HUD
**Subcategory:** Motion and Interaction Feedback

## What you see

Page changes use paired push/pop directions so enter and back read clearly, keeping page title and category visible; under reduced motion swap travel for a short fade without losing function.

## Not to be confused with

Motion must not hide focus or drop input; mashed presses resolve to the latest intent.

## Use it for

Page changes use paired push/pop directions so enter and back read clearly, keeping page title and category visible; under reduced motion swap travel for a short fade without losing function.

## Tunable parameters

push / pop direction · page title · category crumb · transition duration · easing · focus animation · scroll memory · reduced motion

## Request prompt

Design menu hierarchy motion: push child pages in from the right and pop them out the opposite way; keep a Menu › Settings › Audio crumb visible. Use 180 ms panels and 120 ms focus; resolve triple-taps to the latest input; under reduced motion use an 80 ms crossfade still restoring focus and scroll.

## Implementation hint

Enter deeper pages with a paired push direction and leave with the opposite pop so hierarchy is readable. Keep page title and category visible during motion. Cap durations, resolve to the latest input if mashed, and replace travel with a short crossfade under reduced motion while still restoring focus and scroll.
