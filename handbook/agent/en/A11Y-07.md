# A11Y-07 · Hold / Toggle input mode

**Aliases:** 按住或切換; 長按改開關; Hold versus toggle; Sticky interaction mode; ホールド／トグル

**Group:** Readability & accessibility
**Subcategory:** Input modes

## What you see

Continuous actions (sprint, aim, crouch, wheels) offer both hold-to-engage and press-to-toggle, user-selectable, with clear state cues in toggle mode.

## Not to be confused with

Not key rebinding in general — only hold vs toggle for sustained actions.

## Use it for

Fatigue and mobility accessibility; shared mouse/pad schemes.

## Tunable parameters

per-action mode · HUD state icon · default by platform · no mid-combat force (starting points)

## Request prompt

Expose Hold/Toggle for sprint, aim, crouch and wheels; show a HUD state icon in Toggle. Defaults may vary by platform but must be changeable. Do not force mid-combat switches.

## Implementation hint

InputAction.mode = Hold|Toggle; Toggle flips latched state on press; Hold follows button down. UI reads latched for icon.
