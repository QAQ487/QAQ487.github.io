# UI-23 · List–detail / master–detail layout

**Aliases:** 清單加詳情面板; 左邊揀右邊出數值; 設定旁即時示範; Master-detail; List detail pane; Split view UI; リスト＋詳細; マスターディテール

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

A list on the left (or top) stays paired with a persistent detail pane showing the focused item’s name, stats and use. Focus only refreshes the pane; confirm equips or applies. On narrow screens, drill into a detail page and restore focus plus scroll on back. Settings can live-preview subtitles in the pane. Short hover tips are UI-12; this is a resident detail region.

## Not to be confused with

Not a tooltip (UI-12) and not a modal (UX-08). List–detail is a same-layer master/detail split (or stack).

## Use it for

Inventories, skills, settings, codexes, shops.

## Tunable parameters

list width · detail fields · focus vs confirm · scroll memory · narrow breakpoint · live preview · wrapping · visible action buttons

## Request prompt

Show a list on the left and a persistent detail pane on the right with the focused item’s name, stats and use. Focus only updates the pane; confirm equips. On narrow screens open a detail page and restore focus and scroll on return. Settings may live-preview subtitles in the pane.

## Implementation hint

Two panels share one selection model: list.index drives detail view-model; commit on confirm. Persist {tab, index, scrollY} when pushing a detail route on small screens. Keep primary actions inside the detail footer so wrapped text never covers them (XAG 114).
