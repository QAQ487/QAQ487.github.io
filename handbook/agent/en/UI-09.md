# UI-09 · Off-screen indicator / Edge arrow

**Aliases:** Off-screen pointer; Screen-edge marker; Offscreen target indicator; Edge arrow

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

When a target (objective, ally, enemy) is outside the view, an arrow or icon appears on the screen edge pointing to it, sliding along the edge to stay accurate, often with a distance number; the same pattern can ring the avatar with yellow/red arrows for off-screen incoming attacks (blockable vs unblockable). Once on-screen, the edge arrow yields to an overhead marker.

## Not to be confused with

Not a minimap (UI-08, a separate thumbnail); an edge arrow sits directly on the main view’s border. A brief damage-direction flash can coexist with a sustained off-screen attack/objective arrow (Enemy Off-screen indicator accessibility patterns).

## Use it for

Escorts, finding objectives, tracking teammates in multiplayer, enemies approaching from off-screen.

## Tunable parameters

edge inset · arrow size & colour per target type · distance text · fade near edge · on-screen marker swap · clustering of overlapping arrows

## Request prompt

Add edge arrows for off-screen objectives in your game: cast a ray from screen centre towards the target, intersect it with the screen rectangle inset by 10 px, draw a 9 px gold arrow at that point rotated to face the target and show the distance (e.g. "24m") next to it; when the target comes on screen, swap the arrow within 0.15 s for a 6 px bobbing marker above the target. If several arrows overlap, sort by distance and offset them by 10 px.

## Implementation hint

Project the target to screen space; if inside the safe rect show the on-screen marker. Otherwise d = target - centre, t = min(halfW/|d.x|, halfH/|d.y|), pos = centre + d*t, angle = atan2(d.y, d.x). For 3D targets behind the camera, flip d before clamping.
