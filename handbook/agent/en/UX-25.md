# UX-25 · Landmark / Navigational landmark；POI

**Group:** Visual guidance & wayfinding
**Subcategory:** Spatial Recognition and Guidance

## What you see

A distinctive tower, red bridge, or giant statue lets you say, “Go back to the base of the tower, then turn left.” A useful landmark anchors memory.

## Not to be confused with

POI only means a place worth noticing; it does not guarantee navigational value. Attractive distant decoration that cannot be seen from relevant locations or does not help distinguish directions may not function as a navigational landmark.

## Use it for

A distinctive tower, red bridge, or giant statue lets you say, “Go back to the base of the tower, then turn left.” A useful landmark anchors memory.

## Tunable parameters

distinct silhouette · multi-angle visibility · route reference · memory anchor · scale · POI distinction

## Request prompt

Create a 30 m triangular tower visible from 3 major junctions so routes can be described as turn left at the tower base; add 2 exploration-only POIs, but do not treat an attractive statue hidden from junctions as a navigational landmark.

## Implementation hint

Choose a landmark with a unique silhouette and expose it from relevant decision points with stable directional relationships. Test whether players can use it to describe and recover a route, rather than assuming any attractive point of interest provides navigation.
