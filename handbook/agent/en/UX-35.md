# UX-35 · Backward gate / One-way entrance / Point of no return

**Group:** Visual guidance & wayfinding
**Subcategory:** Access Rules, Returning, and Learning

## What you see

Dropping from a high ledge or a collapse behind you prevents return by the same route, narrowing the scope of subsequent exploration.

## Not to be confused with

These three terms are not fully synonymous. One-way may apply only to this route segment, whereas point of no return often emphasizes losing access to a larger area as progression advances. One drop does not prove that every secret in the chapter is now missed.

## Use it for

Dropping from a high ledge or a collapse behind you prevents return by the same route, narrowing the scope of subsequent exploration.

## Tunable parameters

one-way edge · return scope · warning · local loop · point of no return · save state

## Request prompt

Design a 3 m drop as a local one-way entrance that cannot be climbed back but loops around within about 8 minutes; separately show one confirmation before the chapter-ending point of no return to the previous 4 areas, listing unfinished side objectives.

## Implementation hint

Encode the connection as one-way and state exactly which area or route becomes inaccessible. Reserve stronger point-of-no-return warnings for larger irreversible progression changes, and verify save and collectible consequences before committing.
