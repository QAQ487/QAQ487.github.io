# UX-05 · Contextual prompt / Context-sensitive help

**Aliases:** Dynamic input glyphs; Device-aware prompts; 即時按鍵圖示; 入力図柄の切替

**Group:** UI & HUD
**Subcategory:** On-screen Information and Menus

## What you see

Contextual prompts appear only near valid interactables; glyphs follow the active device and live bindings—after a gamepad connects, E becomes A (or your rebound control) immediately.

## Not to be confused with

A disappearing prompt does not mean mastery; range or facing may have changed. Stick drift inside the dead zone must not flicker glyphs.

## Use it for

Contextual prompts appear only near valid interactables; glyphs follow the active device and live bindings—after a gamepad connects, E becomes A (or your rebound control) immediately.

## Tunable parameters

interaction range · facing angle · action label · bound input · device glyphs · rebind refresh · stick-drift ignore · priority · dismissal

## Request prompt

Create a contextual prompt that shows the live bound glyph when the player is within 2 m of a chest and facing it within 45 degrees. After a gamepad connects, replace E with A (or the real binding) immediately, and refresh again after rebinds; ignore stick drift inside the dead zone. Hide 0.3 seconds after leaving range and prefer the nearest valid overlapping target.

## Implementation hint

Evaluate prompts from range, facing, eligibility and priority, then render glyphs from the active input device and the live binding table. Swap keyboard letters for gamepad face buttons the moment the device changes or a rebind lands; ignore stick drift below the dead zone so glyphs do not flicker. Hide when conditions fail — never because the system assumes mastery.
