# UI-08 · Minimap

**Aliases:** Mini-map; Radar; Overview map

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

A shrunken map in a screen corner shows the surrounding terrain, the player position (often a blinking dot or heading arrow), enemy and objective icons, plus world pins placed via the reticle (kept in sync with UX-04 aimed pins), and sometimes a frame for what the main view currently shows; as the player moves, the dot or the map moves with them.

## Not to be confused with

Not an off-screen indicator (UI-09, an arrow on the main view’s edge); a minimap is a separate thumbnail. Not a fullscreen map (opened separately, covers the game).

## Use it for

Open maps, tower defence/RTS, dungeon crawling; tells the player where they are and where threats come from without opening the big map.

## Tunable parameters

scale · north-up vs player-up rotation · shape (rect/circle) · icon set & priority · viewport frame · fog of war on map

## Request prompt

Add a 56×40 px minimap to the top-right of your game: draw the whole map at 1/8 scale (ground, roads and buildings as simple colour blocks); the player is a white square blinking on a 1 s cycle, enemies are red dots and the objective is a gold star; outline the main camera’s visible area with a 1 px white frame. Give it a 1 px dark border and a 50% transparent backing, and keep it off important play areas.

## Implementation hint

Render the map layer once into a small render target (or keep a pre-baked minimap texture), then each frame draw it with a scissor/circular mask and draw icons on top from world→minimap coordinates (pos * scale + offset). For a rotating minimap, rotate around the player in UV space.
