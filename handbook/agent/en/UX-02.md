# UX-02 · Resource meter / Status bar

**Group:** UI & HUD
**Subcategory:** On-screen Information and Menus

## What you see

A shrinking bar, fewer segments, or a counting-down number helps you estimate how much longer you can last or how many more actions you can perform. Search `HUD resource meter health stamina`.  Stamina meters often drive climb/glide (ACT-40); this entry focuses on how the meter is shown and read.

## Not to be confused with

Not everyone can distinguish an icon simply because it is red; combine color with shape, patterns, or text. Bar length does not necessarily represent values linearly; check the rules.

## Use it for

## Tunable parameters

current value · maximum value · segments · percentage · low-state cue · color-independent coding

## Request prompt

Create health and stamina meters: show health as a 0–100% bar plus a number, add hatching and a Critical label below 20%, and divide stamina into 5 segments consumed 1 at a time without relying on red and green alone.

## Implementation hint

Map the meter fill to the documented value scale and pair color with text, shape, or pattern. Define explicit thresholds and animate value changes briefly without delaying the underlying state update.
