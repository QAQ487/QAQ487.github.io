# UX-41 · Objective voting

**Aliases:** 目標投票; 小隊投票; Mission vote; Squad vote; 投票UI

**Group:** UI & HUD
**Subcategory:** Multiplayer cues

## What you see

At a mission fork, players vote on options (attack / stealth / retreat). The UI shows live tallies; when the timer ends or everyone has voted, the majority runs.

## Not to be confused with

Not personal objective tracking (UX-04). Not a ping (NAV-14).

## Use it for

Co-op mission forks, lobby map votes, post-encounter route choice.

## Tunable parameters

option count · timer · change-until-lock · tie-break rule · result toast (starting points)

## Request prompt

Show 2–4 option cards with per-player avatars; 15–20 s countdown; allow vote changes until lock. On ties use leader vote or random (state which in UI). Toast the result.

## Implementation hint

Replicate votes; on timer or unanimous: resolve majority; broadcast outcome; start next objective.
