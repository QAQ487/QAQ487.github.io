# UI-25 · HUD safe area / viewport anchors

**Aliases:** HUD 安全區; 超寬屏血條太遠; 分割畫面字被切; Safe zone; Viewport anchors; Overscan margins; セーフエリア; ビューポートアンカー

**Group:** UI & HUD
**Subcategory:** HUD & interface types

## What you see

HUD widgets anchor inside each player’s visible safe area. On ultra-wide, TV overscan, splitscreen and long translations they inset or reflow instead of sitting on clipped edges. When space is tight, stacking order changes.

## Not to be confused with

Not text scaling itself (A11Y-02); safe area is fitting inside the visible region. Not freeform HUD edit (UI-26), though edit results still clamp to the safe area.

## Use it for

Console TV, ultra-wide PC, local splitscreen, multilingual UI.

## Tunable parameters

safe margin % · per-player viewport · anchor presets (TL/TR/BL/BR/center) · reflow breakpoints · splitscreen gutters · long-string soak

## Request prompt

Anchor the HUD to each player’s safe area, reflow when space is tight, and verify narrow, ultra-wide, splitscreen and longer translations.

## Implementation hint

Define safeRect = viewport inset by platform margins (and per splitscreen pane). Each widget has an anchor + offset; on resize, recompute positions and optionally switch layout presets. Clamp edited positions (UI-26) into safeRect. Test with 200% text (A11Y-02) and German-length strings.
