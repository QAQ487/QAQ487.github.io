# PP-08 · Gaussian blur

**Aliases:** Kawase blur; Dual Kawase blur; Box blur; Background blur; Screen blur

**Group:** Post-processing & screen filters
**Subcategory:** Blur & distortion

## What you see

The whole image (or background) becomes evenly soft with no direction; common behind pause menus or dialogue so the foreground UI reads clearly.

## Not to be confused with

Not depth of field (REN-34, blurring only in front of/behind the focus by distance) nor radial blur (PP-07, directional). Gaussian/Kawase is uniform, directionless blur; they differ only in algorithm (Kawase takes a few samples at growing offsets over several passes, approximating a Gaussian more cheaply).

## Use it for

Pause menus, inventory or dialogue backdrops, frosted-glass UI, an internal step of bloom and other effects.

## Tunable parameters

radius / sigma · pass count · downsample factor · algorithm (separable Gaussian / Kawase / dual filter / box) · dim amount

## Request prompt

Blur the background when the game is paused: downsample the frame to 1/2 resolution and blur with 4 dual-Kawase passes (down then up), about an 8 px equivalent radius; ramp the radius from 0 over 0.2 s as the pause menu opens and multiply background brightness by 0.7; blur once when pausing and cache the result instead of recomputing every frame.

## Implementation hint

Separable Gaussian: horizontal then vertical pass, using bilinear taps between texels to halve sample count. Kawase: each pass samples 4 diagonal taps at offset (i+0.5) texels, ping-ponging between two targets. Dual filter: progressively downsample then upsample with 4–8 taps per pass.
