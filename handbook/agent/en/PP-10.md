# PP-10 · Sharpening

**Aliases:** CAS; Contrast adaptive sharpening; Unsharp mask; Sharpen filter

**Group:** Post-processing & screen filters
**Subcategory:** Blur & distortion

## What you see

Edges and details become crisper with more local contrast and textures look “crunchier”; overdone, bright/dark halos appear around edges and noise is amplified.

## Not to be confused with

Not anti-aliasing (REN-39, which smooths jaggies); sharpening does the opposite and boosts edges. Often paired with upscaling (REN-42) or TAA (REN-40) to win back the softness they cause.

## Use it for

Compensating TAA or low-res upscaling softness, clearer distant textures, the “sharpness” slider in graphics options.

## Tunable parameters

sharpness amount · kernel (cross / 3×3) · adaptive limit · run before/after upscale · noise threshold

## Request prompt

Add a sharpening post-process to the game, run last before UI: use contrast adaptive sharpening (CAS), estimating local contrast from a 5-tap cross; sharpen low-contrast areas more and high-contrast edges less to avoid halos; sharpness slider 0–1 (default 0.4), default 0.6 when TAA or upscaling is on.

## Implementation hint

Unsharp mask: out = src + amount*(src - blur(src)). CAS-style: from the 4-neighbour cross get min/max; w = sqrt(min(minC, 1-maxC)/maxC) * lerp(-1/8, -1/5, sharpness); out = (src + w*(n+s+e+w4)) / (1 + 4w). Clamp to avoid ringing.
