# PP-15 · Selective colour / Colour splash

**Aliases:** Selective colour; Colour splash; Colour isolation; Leave-one-colour; 局部保色; 選擇性留色; 黑白留紅; パートカラー; 部分カラー; 色残し

**Group:** Post-processing & screen filters
**Subcategory:** Stylistic filters

## What you see

An almost monochrome world containing one vividly coloured subject or colour family. The kept subject retains its original hue, shading, and moving silhouette.

## Not to be confused with

PP-06 desaturates everything. NAV-08 is an investigation system with clue trails. A11Y-06 recolours important silhouettes for readability. Distinct from the Photoshop “Selective Color” CMYK mixing tool — same English name, different meaning.

## Use it for

Highlighting one important object, a red coat in memory, poster-style leave-one-colour.

## Tunable parameters

kept hue range or object mask · feather · desaturation amount · subject ID (authoring defaults)

## Request prompt

Enter selective-colour presentation → environment and chosen subject → desaturate surroundings while preserving the subject’s original colour, shading and moving silhouette → return all colours on exit.

## Implementation hint

Desaturate the frame, then restore colour where a subject mask or hue distance says keep. Prefer an object/ID mask for a moving coat so shading stays; hue-only keep is a cheaper alternate. Exclude HUD.
