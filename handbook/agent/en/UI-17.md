# UI-17 · Animated text (wave, shake, rainbow)

**Aliases:** Text effects; Rich-text effects; Wavy text; Shaky text; Rainbow text

**Group:** UI & HUD
**Subcategory:** Text & dialogue

## What you see

Some of the already-visible characters keep moving individually: rising and falling one after another (wave), jittering randomly by a pixel (shake, for fear or anger), or cycling colours along the string (rainbow); only tagged words are affected and the rest stays still.

## Not to be confused with

Not a typewriter effect (UI-15, which controls when characters appear); animated text is continuous motion after they appear. Not an error shake (UI-04, a whole UI element shaking once).

## Use it for

Emphasising keywords, conveying emotion (trembling, shouting, spells), rare item names; gives dialogue a tone of voice.

## Tunable parameters

amplitude (px) · speed · per-character phase offset · shake re-roll rate · hue speed & spread · which effects reduced-motion disables

## Request prompt

Add 3 text-effect tags to your game’s dialogue system: <wave> sets each character’s y offset to 2 px × sin(time × 6 + index × 0.6); <shake> gives each character a random ±1 px offset re-rolled every 0.05 s (seeded, not smoothed); <rainbow> sets each character’s hue to time × 120° + index × 30°. Effects apply only inside the tags, and wave and shake can be turned off by the reduced-motion option.

## Implementation hint

Render text as per-glyph quads; in the vertex stage (or CPU) offset each glyph by f(time, glyphIndex) for glyphs inside an effect range parsed from the markup. For pixel fonts round offsets to whole pixels. Use a seeded hash of (floor(time*rate), index) for shake so it is stable and scrub-able.
