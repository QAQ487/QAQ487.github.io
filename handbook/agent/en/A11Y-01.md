# A11Y-01 · Text contrast, backplate and dual outline

**Aliases:** 字幕看不清; 白字在雪地看不見; 字幕被爆炸蓋過; Subtitle backplate; Text background plate; Text outline / stroke; Contrast ratio; Legibility on busy backgrounds; コントラスト比

**Group:** Readability & accessibility
**Subcategory:** Text legibility

## What you see

Subtitles, prompts and damage numbers sit on a changing picture: white text vanishes on snow or in an explosion flash, dark text vanishes in a dark room. The legible approach is a semi-transparent dark plate behind the text (a backplate, with player-adjustable opacity), or a dual outline — dark inside and light outside, or the reverse — so the text keeps a ring of contrast whether the background is bright or dark. Check contrast on the final composited frame (4.5:1 for text and 3:1 for large text are the common thresholds).

## Not to be confused with

Not foreground–background separation (NAV-03, which handles the value hierarchy between characters and scenery), and not multimodal redundant cues (UX-18) or what captions say (UX-10, FX-36). This entry is only about the letters themselves being readable on any background.

## Use it for

Subtitles, dialogue boxes, world-space name tags and damage numbers, HUD text overlaying the scene; test snow, desert, explosion, flash and dark-room scenes in particular.

## Tunable parameters

backplate colour / opacity (player-adjustable) · padding and corner radius · outline width and inner/outer colours · drop shadow vs outline · contrast thresholds (4.5:1 text, 3:1 large text/inactive) · which text gets which treatment

## Request prompt

Add legibility settings to the game's subtitles and world-space text: draw a rounded dark backplate behind subtitles with opacity adjustable from 0% to 100% in settings (default 60%); give name tags and damage numbers a 1 px dark inner outline plus a 1 px light outer outline. Measure contrast on final-frame screenshots: at least 4.5:1 for normal text and 3:1 for large text, checked on snow, the centre of an explosion and a pitch-black room.

## Implementation hint

Draw the backplate as a nine-slice quad sized from the measured text bounds (UI-14) in the same UI pass, before the glyphs. Outlines: SDF/MSDF fonts give inner and outer outline bands in one shader (two thresholds, two colours); bitmap fonts need pre-baked outline glyphs or 8-direction offset draws. Compute contrast with the WCAG relative-luminance formula on linear values (DIAG-02) sampled from the final frame behind the text, e.g. a debug overlay that reads back the back buffer region and prints the ratio.
